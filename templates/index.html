How each output is computed

Segmentation: {{ "a trained U-Net CNN" if mode == "cnn" else "a documented RGB spectral-index heuristic (no learning capacity — train the U-Net for production accuracy)" }} assigns each pixel to Urban, Forest, Water, Agriculture, or Bare land.

Vegetation index: a proxy-NDVI (Excess Green: 2G−R−B) rendered on a brown→yellow→green ramp. Swap in a real NIR band for true NDVI = (NIR−R)/(NIR+R).

Confidence map: CNN mode shows 1 − normalized softmax entropy per pixel; heuristic mode shows the margin between the top rule and its runner-up.

Landscape metrics: patch count, mean patch size, and edge density per class — standard fragmentation indicators (FRAGSTATS-style) used in landscape ecology to describe habitat fragmentation and urban sprawl pattern, not just raw area.

Change-detection summary: Urban Expansion Rate = % of the scene newly converted to Urban; Vegetation Loss Rate = % of previously vegetated (Forest+Agriculture) area converted to something else.

Large images (CNN mode): rather than squashing a whole scene down to the model's 256×256 input and losing detail, large images are classified with overlapping sliding-window tiles that are stitched back together at full resolution.

History: every run is logged to a local SQLite database (history.db) so past analyses survive a page refresh or server restart — see the History tab.

Reports: the "Export PDF report" buttons build a print-ready document (maps, statistics table, vegetation index, landscape metrics) via ReportLab, server-side.

Land-cover classes: Urban · Forest · Water · Agriculture · Bare land. Click a legend swatch to isolate that class in the map.
